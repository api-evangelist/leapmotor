# Leapmotor

> Zhejiang Leapmotor Technology Co., Ltd. (HKEX: 9863) is a Chinese intelligent electric vehicle manufacturer founded in 2015 and headquartered in Hangzhou. It builds battery-electric and range-extended (REEV) passenger vehicles — the T03 city car and the B03X, B05, B10 and C10 SUVs — on its own vertically integrated LEAP platform, developing electric drive, battery, and intelligent cockpit and driving systems in house. Stellantis took a stake in 2023 and distributes Leapmotor vehicles in Europe and export markets through the Leapmotor International joint venture.

## API status

Leapmotor publishes **no public developer API program**. As of 2026-07-19 there is no developer portal, no API documentation, no API reference, no OpenAPI/AsyncAPI description, no public SDKs, no sandbox, and no MCP server. Probing `developer.leapmotor.com`, `open.leapmotor.com`, `api.leapmotor.com` and `iot.leapmotor.com` returned no resolving host, and no Leapmotor host serves a `/.well-known/` discovery document or an `llms.txt`.

The company does operate connected-vehicle services — the Leapmotor mobile app, over-the-air software updates, and the "Leapmotor Connected Experience" — but the vehicle-cloud interfaces behind them are private, authenticated with the mobile app's own mTLS client certificate, and are only reachable through unofficial community clients. Treat any Leapmotor "API" you encounter as reverse-engineered and unsupported.

`itp-open.leapmotor.com` ("ITP — 智能技术信息平台", Intelligent Technology Information Platform) exists and responds, but serves a login-gated single-page application with no public documentation; it is not a developer API portal.
